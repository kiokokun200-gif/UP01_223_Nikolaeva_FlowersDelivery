

УП.01.01
WPF-приложение для сервиса доставки цветов и подарков с подключённой базой данных Microsoft SQL Server.
Выполнила Николаева Мария 4ИСИП-223
## Описание приложения

Приложение представляет собой WPF-клиент для сервиса по доставке цветов и подарков,
работающий с базой данных Microsoft SQL Server через Entity Framework. Клиент может
просматривать каталог товаров, искать, фильтровать и сортировать их, управлять
личным кабинетом и менять пароль. Администратор получает доступ к панели управления
товарами и заказами, построению диаграмм и экспорту отчётов в DOCX, PDF и XLSX.
В приложении реализованы авторизация с хэшированием паролей и капчей, разграничение
ролей, смена темы с сохранением выбора в базе данных, а также
проверка вводимых данных и подтверждение опасных действий.

## Стек технологий

- **Язык:** C# (.NET Framework)
- **СУБД:** Microsoft SQL Server
- **Доступ к данным:** Entity Framework 
- **Отчёты:** Microsoft Office Interop (Word, Excel), экспорт в PDF
- **Диаграммы:** System.Windows.Forms.DataVisualization.Charting
- **Хранение паролей:** SHA1-хэширование
- **Контроль версий:** Git



## Структура проекта

| Папка | Назначение |
|---|---|
| `Model/` | Модель Entity Framework (`.edmx`, классы сущностей) |
| `Pages/` | Страницы приложения (авторизация, каталог, кабинет, администрация, диаграммы) |
| `Windows/` | Диалоговые окна (товары, заказы, смена пароля) |
| `Themes/` | Словари стилей  |
| `res/` | Ресурсы: изображения товаров, иконки |
| `db/` | Скрипт создания базы данных (`schema.sql`) |
